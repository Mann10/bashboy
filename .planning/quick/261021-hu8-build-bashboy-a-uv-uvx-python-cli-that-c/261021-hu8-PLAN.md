<objective>
Build BashBoy end to end as specified in `BRIEF.md`: a stdlib-only Python CLI that classifies shell
commands as `allow`/`deny` using a structural allowlist, a hard denylist, and the Clocked clocked/fill
model API, plus deny-only integrations for Claude Code (PreToolUse) and OpenCode (V2 plugin with V1
fallback), an idempotent installer, an offline test suite, and operator documentation.

Purpose: an agent should not be able to run a destructive shell command just because nobody was
watching — and the gate must never grant permissions it wasn't asked to grant.

Output: an installable package runnable via `uv run bashboy` / `uvx bashboy`, `uv run pytest`
green offline, and all five acceptance commands from BRIEF.md §Acceptance verified.

**Every decision in BRIEF.md is locked.** Do not substitute libraries, rename sources, add caching,
add an audit log, add an `ask` verdict, or auto-approve anything.

`src/bashboy/rules.py` (LOCKED semantics — structure, not string matching):

1. `SHELL_METACHARS = set(";|&$`<>(){}\\\n\r\0*?~#[")` plus backtick. `check_allowlist(command)`:
   - strip; empty → None.
   - if any char of the command is in `SHELL_METACHARS` → return None. This is the structural gate
     that makes `ls; rm -rf /`, `echo $(whoami)`, `ls > x`, `ls && pwd` non-allowlistable.
   - Tokenize on whitespace. The head token must be one of:
     `ls, pwd, cd, cat, head, tail, wc, grep, rg, find, echo, which, whoami, date`.
     For heads in `{git, uv, python, node}` require a matching sub-command prefix:
     `git status|diff|log|show|branch`, `uv --version`, `python --version`, `node --version`.
     Sub-command match is on the first non-flag token after the head (for `git`), or exact
     `--version` (for `uv`/`python`/`node`).
   - `cd` is allowlisted only when it has ≤1 argument, and the argument contains no `~`/`$`/`*`
     (already excluded by metacharacters) — plain `cd /tmp` allows.
   - Return a stable label, e.g. `"git status"`, `"ls"`, else None.
   - Do **not** attempt to parse quotes, env assignments, or PowerShell. Anything unusual → None →
     model path. False negatives are safe; false positives are not.
2. `segments(command)`: return `[command]` plus every piece split on `;`, `&&`, `||`, `|`, `\r?\n`.
   Additionally collect command-substitution bodies by scanning for `$( ... )` (balanced-paren naive
   scan, nested ok) and backtick spans, and append those bodies; recurse one level into each body so
   `echo $(echo $(rm -rf /))` is covered. Cap recursion depth at 5 to avoid pathological input.
3. `DENY_RULES: list[tuple[re.Pattern[str], str]]`, all `re.IGNORECASE`, applied to the raw command
   and to every element of `segments(command)`. Required coverage with concise reasons:
   - recursive/forced remove against dangerous targets:
     `\brm\s+(?:-[a-zA-Z]+\s+)*(?:-[a-zA-Z]*[rf][a-zA-Z]*\s+)*` followed by a target in
     `(/|/\*|/usr\S*|/etc\S*|/var\S*|/bin\S*|/boot\S*|/home\S*|~|~/|~/\*|\$HOME|\$HOME/|\$HOME/\*|\*)`.
     Reason `"recursive delete of a protected path"`. Also match `\brm\s+-[a-zA-Z]*[rf]` with the
     target `/` even when `-r` and `-f` are separated (`rm -r -f /`).
   - `\bmkfs(\.[a-z0-9]+)?\b` → `"filesystem creation on a device"`
   - `\b(fdisk|parted|diskpart)\b` → `"disk partitioning"`
   - `\bformat\s+[a-z]:` → `"drive format"`
   - `\bdd\b[^\n]*\bof=/dev/` → `"raw write to a block device"`
   - `>\s*/dev/(sd|hd|nvme|disk|vd)` → `"raw write to a block device"`
   - `\bshred\b[^\n]*/dev/` → `"shred of a block device"`
   - fork bomb: `:\s*\(\s*\)\s*\{[^}]*:\s*\|\s*:[^}]*&\s*\}\s*;\s*:` →
     `"fork bomb"`
   - `\bchmod\s+(?:-[a-zA-Z]+\s+)*777\s+/(?:\s|$)` → `"world-writable root"`
   - `\bchown\s+(?:-[a-zA-Z]+\s+)*\S+\s+/(?:\s|$)` → `"ownership change on root"`
   - `\b(shutdown|reboot|halt|poweroff)\b` → `"host power control"`
   - `(?i)remove-item\b[^\n]*-recurse[^\n]*(?:\b[a-z]:[\\/]?\s*$|\s/["']?\s*$)` →
     `"recursive delete of a drive root"`
   - `\bgit\s+clean\s+-[a-zA-Z]*[fdx][a-zA-Z]*[^\n]*(?:\s/(?:\s|$)|\s--\s+/)` →

4. `check_denylist(command, cwd=None)`:
