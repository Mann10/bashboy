# Roadmap: BashBoy

## Overview

One milestone: ship a working safety gate that a real Claude Code and OpenCode user can
install and trust. Ad-hoc work is tracked in `.planning/quick/`; this roadmap only records
the durable shape of the project.

## Milestone 1: Working Gate (v0.1)

**Goal:** `uvx bashboy check --command "<cmd>"` returns a correct verdict, and both host
integrations install and block a destructive command.
